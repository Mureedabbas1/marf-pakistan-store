# MARF PAKISTAN — Storefront

A fresh, independent storefront project. This repository is separate from `marf-pakistan-theme`.

## Current build
- Responsive luxury black and champagne-gold design
- Editorial hero section with CSS motion and 3D hover perspective
- Collection cards, product preview filters, search panel, and shopping-bag preview
- Scroll reveal animations with reduced-motion accessibility support
- Mobile navigation

## Important
This is the **front-end preview**, not a live checkout. Product names/images are placeholders; no real orders are submitted and no payment information is collected. Cash-on-delivery order handling, Supabase database, product administration, delivery settings, policies, and custom domain must be configured before launch.

## Run locally
Open `index.html` in a browser, or serve the folder with a static web server.
